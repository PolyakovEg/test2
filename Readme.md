# API для работы с БД студентов и групп

Программный интерфейс, позволяющий выполнять CRUD операции со связанными таблицами студентов и академических групп.
<!--Основные технологии-->

## Основные технологии

PHP 8.1, БД Oracle, DoctrineORM, nginx, php-fpm.

<!--Пользовательская документация-->

## Документация

### Для создания или обновления студента в БД передайте параметры:

| Параметр          | Описание                                                                                      |
|-------------------|-----------------------------------------------------------------------------------------------|
| act               | Student                                                                                       |
| method            | save                                                                                          |
| id                | уникальный идентефикатор студента при обновлении существующего (при создании нового не нужен) |
| lastName          | Фамилия                                                                                       |
| firstName         | Имя                                                                                           |
| patronymic        | Отчество (необязательный)                                                                     |
| email             | Электронная почта   (необязательный)                                                          |
| isLiveInDormitory | Живет ли в общежитии (true/false)                                                             |
| groupId           | Уникальный идентефикатор группы студента                                                      |

### Для получения студентов по нужным критериям передайте параметры:

| Параметр          | Описание                          |
|-------------------|-----------------------------------|
| act               | Student (обязательный)            |
| method            | get     (обязательный)            |
| id                | уникальный идентефикатор студента |
| lastName          | Фамилия                           |
| firstName         | Имя                               |
| patronymic        | Отчество                          |
| email             | Электронная почта                 |
| isLiveInDormitory | Живет ли в общежитии              |
| group             | id группы студента                |

Все параметры, кроме act и method, необязательны. Если необязательных критериев не будет, API вернет список из всех
студентов.

### Для создания или обновления академической группы в БД передайте параметры:

| Параметр         | Описание                                                                                  |
|------------------|-------------------------------------------------------------------------------------------|
| act              | Group                                                                                     |
| method           | save                                                                                      |
| id               | уникальный идентефикатор группы при обновлении существующей (при создании новой не нужен) |
| name             | название группы                                                                           |
| studyStartDate   | Дата начала обучения в формате "ДД.ММ.ГГГГ"                                               |
| specializationId | Уникальный идентефикатор направления подготовки                                           |
| formOfEducation  | Форма обучения - очная/заочная в формате строки                                           |

### Для получения всех групп по id группы передайте параметры:

| Параметр         | Описание                                        |
|------------------|-------------------------------------------------|
| act              | Group   (обязательный)                          |
| method           | get     (обязательный)                          |
| id               | уникальный идентефикатор группы                 |
| name             | название группы                                 |
| studyStartDate   | Дата начала обучения в формате "ДД.ММ.ГГГГ"     |
| specializationId | Уникальный идентефикатор направления подготовки |
| formOfEducation  | Форма обучения - очная/заочная в формате строки |

- Все параметры, кроме act и method, необязательны. Если необязательных критериев не будет, API вернет список из всех
  групп.

### Для удаления студента (группы) по id из БД передайте параметры:

| Параметр | Описание                                   |
|----------|--------------------------------------------|
| act      | Student (Group)                            |
| method   | delete                                     |
| id       | уникальный идентефикатор студента (группы) |

### Для получения всех студентов группы по id группы передайте параметры:

| Параметр | Описание                        |
|----------|---------------------------------|
| act      | Group                           |
| method   | get                             |
| id       | уникальный идентефикатор группы |

### Для получения даления студентов группы по id группы передайте параметры:

| Параметр | Описание                        |
|----------|---------------------------------|
| act      | Group                           |
| method   | get                             |
| id       | уникальный идентефикатор группы |
